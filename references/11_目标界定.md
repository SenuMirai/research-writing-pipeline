# 11　目标界定：收什么、不收什么

> **这一阶段的价值最高、最容易被跳过。** 它决定你后面几个月是在"用资料"还是在"搬资料"。

## 1. 针对性铁律：每条材料必须能指到小节

**判据**：这条材料**能证明大纲哪一节的哪个分论点**？
- 答得出 → 收；
- 答不出 → **先收手**（可以登记在"待判定"清单，但不要下载全文、不要进台账）。

**为什么这条最重要**：资料一旦入库，就要编号、入台账、进交付包、进分析文档——
**每条料都有后续成本**。收了用不上的，成本全白付。

**实测教训**：曾因"某类资料听起来相关"而批量抓了 700 条（某传统工艺资料集），
结果时段不符（属背景时段）、论点不对（属工艺史而非文化自主性），**全部作废**。

## 2. 时段铁律：先判定材料落在哪个时段

**三问**：
1. 这条材料的**产生时间**是哪年？（不是内容涉及的年代）
2. 它落在**核心时段**还是**背景时段**？
3. 如果是背景时段——**它对核心时段的论证是"必要前提"还是"可略"**？

**规则**：
- **背景时段的材料一律不铺开**（只保留能说明"起源形态"的少量关键条目）；
- 核心时段的材料按论点需要收。

## 3. 产出：《材料—论点对应表》

一张矩阵表，**行=材料，列=大纲小节**，命中打钩并标等级：

| 编号 | 材料 | 1.1.1 | 1.1.2 | 2.1.2 | 2.2.1 | … | 缺口 |
|---|---|---|---|---|---|---|---|
| A-012 | … | **A** | | B | | | |
| B-345 | … | | | | **A** | | |

**它同时是四样东西**：
1. **收集清单**（要抓什么）；
2. **进度表**（收了多少）；
3. **缺口表**（哪一列是空的）；
4. **写作索引**（写某节时直接看该列）。

⚠️ **空列 = 论证缺口**：要么补料，要么**改大纲**（把该节合并或降格）。
**不要在写不出来的时候才发现那一列是空的。**

## 4. 收料时的四条判断

| 判断 | 通过线 |
|---|---|
| **对应性** | 能指到具体小节 |
| **时段性** | 落在核心时段（或背景时段的必要前提） |
| **可引性** | 有明确的引用层级与授权（见 `12_检索与获取.md`） |
| **独立性** | 它不是已有材料的重复（去重键不同） |

**四条全过才收。** 有一条不过 → 记入"待判定/不相关登记"（**要留痕**，说明你判断过）。

## 5. 反向清单：明确写下"不收什么"

比"收什么"更能省时间。示例：
```
✗ 背景分期的专题性资料（与核心命题无关者） —— 只作背景交代，不铺开
✗ 无法确定来源与原件的网络转帖 —— 不可核验
✗ 与已有材料重复（同一文档的另一来源）—— 用去重键判
✗ 只有图像没有著录、且无法看图判断的图版 —— 不可引用
```
把反向清单写进项目说明，**下次想抓的时候先看它一眼**。

## 6. 阶段 1 的交付物

```
[ ] 「收什么」清单（按小节列出目标材料类型）
[ ] 「不收什么」反向清单
[ ] 《材料—论点对应表》（初版，随收集更新）
[ ] 缺口清单（哪些小节尚无 A 级材料）
[ ] 不相关登记（已判断为不收的，附理由）—— 留痕，避免重复判断
```
