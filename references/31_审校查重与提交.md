# 31　审校、查重与提交

## 1. 结构化审校：**按类别逐项过，不要通读**

通读会产生"读了很多遍但什么都没改"的错觉。正确做法是**一次只查一类问题，全篇扫一遍**。

### 13 类问题清单（逐类全篇过一遍）

| # | 类别 | 具体查什么 |
|---|---|---|
| 1 | **事实一致性** | 同一事件在不同章是否同一日期/人名/数字；与"不可变事实清单"是否一致 |
| 2 | **时间线** | 事件顺序；涉及年代与推论年代是否冲突（如把"数十年前"写成"百年前"） |
| 3 | **引注与编号** | 编号连续无跳号；正文标注 ↔ 参考文献表一一对应；同一材料是否用了两个编号 |
| 4 | **参考文献著录** | 刊名/年/卷/期/页；是否误写；是否有"待核"未清 |
| 5 | **越级引用** | 凡据"目录级/标题级"材料陈述内容处，一律改为只引題名·日期（或补原文） |
| 6 | **孤证** | 每个论断的独立来源数是否 ≥2 |
| 7 | **一手/二手混列** | 研究判断是否被当作一手材料引用 |
| 8 | **术语与译名一致** | 同一概念的译法、同一人名的写法是否统一（专名表） |
| 9 | **体例与版式** | 逐项对照"体例执行版"（字号/行距/页边距/标题层级） |
| 10 | **摘要与关键词** | 字数、中英一致性；关键词数量与覆盖 |
| 11 | **图表与编号** | 图表编号连续、图注完整、正文有指称；图版是否标注馆藏 |
| 12 | **重复与啰嗦** | 同义段重复；同一材料在不同章重复引用（应择一处或明确交叉引用） |
| 13 | **字数与结构** | 各章篇幅是否失衡；总字数是否达标 |

**做法**：把这 13 条抄成一份 checklist，每轮只勾一类。**全部勾完后再通读一遍收尾。**

## 2. 引注核校（最容易出错、也最容易被扣分）

```bash
# 建议用脚本做机械部分，人工只做判断
python scripts/check_writing_conventions.py --config config.json --md-dir ./正文
#   → 字数/摘要字数/关键词数/引注编号连续性/参考文献条目数与语种比/标题层级完整性
```
**人工必查**
```
[ ] 每条"待核"是否已核（或改为"未核"并说明）
[ ] 刊名是否写全（勿用简称）； иностранные 刊名是否前后一致
[ ] 页码连接符、分隔符是否符合规范（不同规范用「～」/「-」/「,」）
[ ] 是否误加了规范禁止的类型标识（如某些规范明确"不写 [M]/[J]"）
[ ] 一手史料的馆藏标注是否完整（机构名 + 资料代码/档号）
[ ] 图版是否有"某馆藏"标注
```

## 3. 查重

```
[ ] 查重前先自删"引用密集且已正确标注"的段落干扰（部分系统会算重复）
[ ] 报告出来后，逐条判断：是"引用"（有标注）还是"抄袭"（无标注）
[ ] 连续长句重复 → 改写而非仅补注（补注只能解决"未标注"，不能解决"照抄"）
[ ] 一手材料原文引用：应显式加引号/缩排，并在注中标明出处
[ ] 自查自引（自己已发表内容）是否需要说明
```

## 4. 提交前清单（打印出来逐项勾）

```
【内容】
[ ] 摘要（中/英）字数达标、内容一致；关键词数量正确、无泛词
[ ] 目录与正文章节标题逐字一致（含编号层级）
[ ] 结论只使用前文已出现的论据，未引入新材料
[ ] 全文无"待核/TODO/此处待补"残留（或已 明确标注为需导师确认项）

【引注】
[ ] 编号连续、无跳号；正文 ↔ 参考文献表一一对应
[ ] 参考文献类别齐全、语种比达标
[ ] 一手史料注法统一；馆藏标注完整

【版式】
[ ] 字号/字体/行距/页边距/页眉页脚 逐项对照体例执行版
[ ] 图表编号连续、图注位置正确、图版标注馆藏
[ ] 目录页码与正文一致（更新域）

【档案】
[ ] 结构变更记录（版本历史）已归档
[ ] 交付包（台账/总目录/说明）已同步为最终版
[ ] 备份：本地 + 云盘各一份
```

## 5. 提交前后的两件"容易忘"

1. **致谢与附录**：附录放什么要早定（**大表格、逐条材料清单适合入附录**；
   但要注意：**附录不是逃避字数限制的地方**，正文该论证的不能挪到附录）。
2. **可复现性**：把自己的**资料编号体系**与**台账**留一份给未来的自己——
   答辩、修改、后续发表都可能需要回到某条材料；**没有编号体系，三天后你就找不到它了**。
