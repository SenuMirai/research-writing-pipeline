## 一、总表

| 阶段 | 输入 | 核心动作 | 产出 | 出口自检 |
|---|---|---|---|---|
| **0 选题框架与开题** | 兴趣／领域现状／培养单位规范 | 立核心命题、划时段、搭论点树、倒排时间线、提取体例执行版 | 开题报告；大纲；体例执行版 | ①每节能答"要证明什么"②体例成文③时间线有日期④开题要件齐 |

| **2 检索获取** | 目标清单 | 三类入口检索；采集并记录来源/授权/层级/产物关系 | 原件＋采集留档 | 每条有 URL；授权与层级已记；采集参数可复现 |
| **3 语料库工程** | 原始产物 | 定引用单元→去重建全集→编号冻结→台账→交付包 | 编号注册表；总台账；交付包 | 编号变动＝0；提要为空＝0；库级锚点＝0；断链＝0 |

| **5 写作引注** | 分析文档 | 要点→段落；引注落地；守论证纪律 | 正文各章 | 引文可回原件；论断 ≥2 组来源 |
| **6 审校提交** | 初稿 | 结构化审校→引注核校→查重→提交清单 | 定稿 | 13 类问题全绿；版式/字数/摘要合规 |

## 二、逐阶段自检清单

### 阶段 0
```
[ ] 核心命题一句话能说清，且需要论证（非常识、非描述）
[ ] 大纲每节都能回答"这节要证明什么"
[ ] 体例规范已提取为"执行版"表格（字数/引注制式/参考文献类别/版式）
[ ] 时间线从提交倒排，每个里程碑有日期
[ ] 开题要件齐（目的意义/内容概述/研究现状/方法创新/提纲/参考文献）
```

### 阶段 1
```
[ ] 写清了"不收什么"（比"收什么"更能省时间）
[ ] 《材料—论点对应表》已建，行=材料、列=小节
[ ] 抽 10 条新材料都能指到小节
[ ] 每小节 ≥1 条 A 级材料（无料的小节 = 论证缺口）
```

### 阶段 2
```
[ ] 每条材料都有在线来源 URL
[ ] 授权与可引用性已记录（含"刊载是否需申请"）
[ ] 引用层级已记录（全文/要点/目录/标题）
[ ] 产物与引用单元的关系已写明（1:1 / 1:N）
[ ] 采集脚本或参数已留档（换机可复现）
```

### 阶段 3
```
[ ] 每库都声明了 citation_unit（引用单元）与策略（A/B）
[ ] B 方案的库：聚合文件是**去重全集**，且有去重报告
[ ] 编号注册表连跑两次，变动 = 0
[ ] 台账「提要」为空 = 0；「文字粒度」全部已标
[ ] 正文/分析文档中「库级锚点」= 0、「未知编号」= 0
[ ] 交付包内随机抽 1 份 Word：目录在、编号链接可点、目标存在
[ ] 压缩包三档（轻量/演示/完整）体积符合预期
```

### 阶段 4
```
[ ] 每条含：编号·原文·译文·所体现的内容·不得用它证明什么·对接写法·引用格式
[ ] 文献（二手）与史料（一手）**分列**，未混引同一论断
[ ] 关键论断 ≥2 组独立来源（跨库/跨性质）
[ ] 三问答不出者：已标"三问待补"而非硬写
[ ] 越级引用处已显式标注
```

### 阶段 5
```
[ ] 每段引文都能回原件核页
[ ] 每个论断 ≥2 组独立来源
[ ] 正文标注与参考文献表编号一一对应
[ ] 一手史料与二手研究的注法**分开**
[ ] 术语、译名、人名前后一致
```

### 阶段 6
```
[ ] 13 类问题清单全绿（见 references/31）
[ ] 引注编号连续、无跳号；参考文献与正文对应
[ ] 版式逐项对照"体例执行版"
[ ] 摘要字数/关键词数/目录层级合规
[ ] 查重报告已出；重复段落已确认是"引用"而非"抄袭"
[ ] 结构变更记录已归入版本历史
```

## 三、一页速用版（贴在桌边）

```
做题先问三句：证明什么？谁来对？能不能核？
收料先问三句：哪一节？什么层级？怎么引？
写前先问三句：这条料证明什么？不证明什么？还差几条独立来源？
交付先问三句：别人能否自己核验？换台机器还能打开吗？我漏了什么自检？
```
