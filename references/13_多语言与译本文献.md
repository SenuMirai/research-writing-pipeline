# 13　多语言与译本文献

> 人文社科的资料天然是多语的。这一篇只讲**采集与引用层面**的坑（学术层面的翻译问题不在此列）。

---

## 1. 编码：先判，再读

| 语言／来源 | 常见编码 | 症状 |
|---|---|---|
| 非 UTF-8（旧系统、政府站点导出） | `旧编码`/`GB18030` / `GB18030` / `EUC-KR` | 按 utf-8 读全是乱码或方块 |
| 中文（旧系统、Excel 导出） | `GB18030` / `GBK` | 同上 |
| 韩文 | `EUC-KR` / `cp949` | 同上 |
| 通用现代站点 | `UTF-8`（可能带 BOM） | BOM 会让第一列列名多一个不可见字符 |
| 西里尔／阿拉伯／希伯来 | 多为 `UTF-8` | 双向文字（RTL）在表格里易错位 |

**做法**：
```python
for enc in ("utf-8-sig", "utf-8", "旧编码", "gb18030", "euc-kr", "cp1256"):
    try:
        text = raw.decode(enc); break
    except UnicodeDecodeError:
        continue
```
**写出**一律 **UTF-8-BOM**（Excel 直接打开不乱码）。

⚠️ **BOM 的隐蔽陷阱**：`UTF-8-BOM` 读进来的第一个列名会带 `\ufeff`，
导致按列名匹配（如 `header.index("题名")`）失败。**读的时候用 `utf-8-sig` 就能自动去掉。**

---

## 2. 比对与去重：必须做 **NFKC 归一**

多语材料的同一个字符串常有两种写法：
```
全角/半角数字：２０世紀  ↔  20世纪
全角/半角标点：／  ↔  /
异体字/繁体简体：國  ↔  国
```
**去重与匹配前，对两侧同时做 `unicodedata.normalize("NFKC", s)`**，否则会：
- 把同一条材料判成两条（重复入库）；
- 或把本该匹配的引文判为"找不到"（**实测踩过：因全角数字漏配 1 条**）。

⚠️ **归一化只用于比对，写出的原件保持原样**（不要用归一化后的文本覆盖原文）。

---

## 3. 转写（transliteration）与罗马化

- 西里尔／阿拉伯／非 UTF-8 书名与人名的罗马化**必须给规则**（如 ISO 9、ALA-LC、平文式/训令式）；
- **同一篇文内不得混用两套罗马化**；
- 若原著录是罗马化、原文可查，**优先按原文著录，罗马化放括号**。

---

## 4. 译文引用：三条硬规矩

1. **译者与版本必须写全**：`作者. 题名. 译者译. 出版地: 出版者, 年: 页码.`
2. **不得据译文转述而称"原作如此"**：译文可能有误或有删节；
   → 写法：`中译本作"…"`／`原文为"…"`，**两者不可混**；
3. **同一著作引用多个版本时，页码必须标明是哪一版**（原版/修订版/中译本页码不同）。

⚠️ **常见事故**：把"某译本的说法"当成"作者的观点"直接引用，且未标译者。

---

## 5. 双语／多语材料的著录处理

| 情形 | 做法 |
|---|---|
| 一手材料有原文与官方译文（如题名双语） | **原文为主，译文放括号**；著录时两者并出 |
| 材料只有译文 | 明确标 `（译文）`，并注明来源 |
| 档案馆给的著录本身是罗马化／译文 | **照录馆方著录**，不要自行改写（可加注） |
| 同一材料的两个版本（原刊 vs 译本） | **各自编号**，并在台账注明"今天看到的是哪一版" |
| 引用非拉丁文字 | 正文用原文（或通用罗马化）＋首次出现给译文 |

---

## 6. 采集层面的三个多语种坑

| 坑 | 症状 | 防法 |
|---|---|---|
| **检索词只在一种语言里搜** | 漏掉他语文献（如只搜中文，漏掉非 UTF-8／英文同题研究） | 同一概念准备**多语检索词表**（中/英/日/…），逐语检索 |
| **站点按语言分库** | 同一机构的多语页面内容不一致 | 以**原文语言版本**为准，译文页只作参考 |
| **文件名含非 ASCII** | 打包／脚本报错或乱码 | 测试时**放一个含全角与空格的样本**；脚本统一用 UTF-8 路径处理 |

---

## 7. 多语材料在语料库里的字段建议

台账里加三列（或合并为一列 `语言`＋一列 `版本`）：
```
语言：zh / ja / en / ru / ar …
原文/译文：原文 / 译文 / 双语文
版本：原刊 / 修订 / 译本（译者）/ 缩微 / OCR转录
```
**为什么必要**：写作时"这条能不能直接引原话"完全取决于这三项。
