# 03　聚合文件与引用层级

## 1. 四种文字粒度（决定"能引到什么程度"）

| 层级 | 能支撑什么论证 | 典型材料 |
|---|---|---|
| **全文级** | **直接引用原话**、话语分析、修辞分析 | 会议录全文、证言转录、OCR/直取全文、论文全文 |
| **要点级** | 议题脉络、**谁在何时提了什么** | 议案名＋提案人＋会期 |
| **目录级** | 制度事实、法令谱系、数量统计 | 公报题名、法令目录 |
| **标题级** | **"某报某日有某报道"** | 报纸见出、档案卷内目录 |

## 2. 越级引用 = 学术不诚信的最高发区

**最常见的越级**：
- 拿**报纸标题**当**报道内容**用（"该报批评了 X"——标题只说"报道了 X"）；
- 拿**议案名**当**议案内容**用；
- 拿**档案目录条目**当**档案内容**用。

**铁律**：
> **目录级／标题级只能引到「题名·番号·日期」为止，不得据题名陈述内容。**

**正确写法**：
```
✅ 1958 年 8 月 25 日《某报》朝刊第 3 版载有题为「…」的报道。
❌ 1958 年 8 月 25 日《某报》报道了某协会选出 50 余名评议员。（内容未核，越级）
```
**要引内容，就必须回到原件**（缩微胶卷、馆藏、扫描件，或做针对性 OCR）。

## 3. 在台账里如何声明

台账必须有一列 **「文字状态（文字粒度）」**，取值限定为上面四级之一（可加括号说明），例如：
```
全文级（已直取，231/236 页有文字层）
全文级（已 OCR，机器识别·未校）
要点级（発議者·備考；不得据題名陈述内容）
目录级（題名·番号·日期）
标题级（报刊标题；报道正文须回原件）
```
**自检**：该列**不得为空**，且**不得出现"待OCR"却已有全文**这类矛盾状态。

## 4. 三个易错点

### 4.1 「有文字层」≠「可直接引用」
- 扫描件经 **OCR** 得到的文本是**机器识别**，必须标注 `机器识别·未校`，**引用须回原件核页**。
- 人工转录标注 `人工转录`；已校对标注 `机器识别·已校`。

### 4.2 计数口径
- **不要把"格式化后的索引文本"当史料量**。
  例：公报索引 md 有数百万字，但那是含行号/日期/链接的**表格文本**；
  **史料内容只有题名部分**。统计时算错会虚高十余倍。

### 4.3 同一材料的多版本
原刊 / 缩微 / 转写 / OCR / 中译本 —— **各自编号**，并在台账注明
**「今天看到的是哪一版」**。这是"史料批判三问"第三问的直接落点。

## 5. 引用层级声明模板（贴在每个库的说明开头）

```
库：<前缀> <库名>
引用单元：<一条报刊标题 / 一件档案 / …>
落盘策略：A（逐条） / B（共用源编号＋定位式）
引用层级：<全文级 / 要点级 / 目录级 / 标题级>
可引用到什么程度：<例：可引題名·日期·版面；正文须回原件>
不得用于：<例：不得据題名陈述报道内容；不得用于统计报道倾向>
```
**每个库都要有这一段**——它同时约束作者、合作者和未来的自己。
