# 30　写作与引注落地

## 1. 写作不是"重新构思"，而是"把分析阶段写好的写法落成段落"

**分析阶段就该写清**（见 `24_按大纲生成分析.md`）：
```
- 建议用于：<正文哪一处>——<起什么作用>
- 对接论文的写作方法：<放到该节哪个位置、怎么写、结论句是什么>
```
**写作时只做一件事**：把这条材料的"原文/译文/内容/写法"组织成通顺段落，
末尾用**引用格式**里那一句入注。

> **判据**：如果到了写作时还在想"这条材料怎么用"，说明分析阶段没做到位——
> **应当回到阶段 4 补充"对接写法"，而不是在写作时硬凑。**

---

## 2. 段落结构模板（史料入文的标准骨架）

```
① 引出（一句）：这一节的论点是什么
② 摆材料（两到四句）：谁、何时、何处、做了什么/说了什么 —— 引原文（必要时附译文）
③ 分析（一到三句）：这条材料说明了什么（**用材料自己的措辞去推**，如"请注意'名目'二字"）
④ 辨析（可选）：这条材料的界限（"媒体标题只说明有报道，不等于报道内容"）
⑤ 落回论点（一句）：因此……（与本节论点扣合）
```

**要点**：
- **分析要走"材料自己的词"**：把关键措辞逐词解，比套用理论术语有力；
- **不要一段只摆材料不分析**（"资料堆积"），也**不要只分析不落材料**（"空议论"）。

---

## 3. 引注落地三步

### 第一步：确认体例（阶段 0 已定）
- **顺序编码制**：正文按出现顺序标 `[n]`，参考文献表按序排列；
- **作者—年份制**：正文标 `(作者 年份)`，参考文献表按字母序。

### 第二步：分清一手与二手（**最常出错**）
| 类型 | 走哪里 | 说明 |
|---|---|---|
| **二手研究**（论文、专著） | **参考文献表** | 按规范类别著录（图书/期刊/会议论文集/专利/学位论文…） |
| **一手史料**（档案、报纸、证言、图版） | **随文注／注释体** | ⚠️ 若培养单位规范**未列"档案/网页"类型**，**先与导师确认是否单列**，**不要自行发明类别** |

**注释体示例**（按"机构+题名+时间+收藏地"逻辑）：
```
《题名》（资料代码 xxx），某档案馆藏，1958-09-19。
「见出标题」，《报纸名》，1962年12月12日（夕刊2面）。某数据库检索。
《题名》（口述证言，资料代码 xxx），某档案馆藏，録音 00:10:05～00:21:43。
```

### 第三步：编号与链接一致
- 正文标注的编号 ↔ 参考文献表条目 **一一对应，无跳号**；
- 若在电子稿里，`[编号]` 最好同时是**指向原件的超链接**（便于自己与他人核验）。

## 4. 论证纪律（写作期最容易破的五条）

| 违纪 | 表现 | 约束 |
|---|---|---|
| **孤证立论** | 一条材料直接下结论 | 每个论断 ≥2 组**独立**来源（不同性质/不同库） |
| **性质不分** | 拿报纸标题当报道内容、拿议案名当议案内容 | 标注性质 + 遵守引用层级 |
| **混列** | 把研究者的判断与一手材料并列引证同一论断 | **严格分列**，研究判断要写"如某某所指出的" |
| **越级引用** | 据"目录级/标题级"材料陈述内容 | 只引到題名·番号·日期 |
| **文本透明化** | 把官方宣传/公文套话当客观记录 | 对关键措辞**逐词解**，指出其立场与选择性 |

**一句话检验**：**任何一句结论，你能立刻说出它的两处来源吗？** 说不出，这句就先别写。

---

## 5. 引用格式：**不猜，宁缺勿错**

自动生成引用时最常出的错：**从正文抽年份抽到"引文的年份"**（实测：某条本该 1990 年代，自动抽到 1885）。

**分级策略**
| 材料 | 做法 |
|---|---|
| 已人工核过的著录 | 直接用 |
| 期刊论文 | **刊名用白名单**匹配；**年/卷/期/页一律标「待核」** |
| 学位论文 | 文件名含 `digest` 或正文含"学位论文/論文要約" → 按**学位论文**著录，不要硬套期刊 |
| 一手史料 | 随文注体；不确定的字段标「待核」 |

**宁可标"待核"，不可写错信息。**

---

## 6. 写不动时的四个排查

```
1. 这一节的论点是不是不成立？      → 回阶段 1 看该节材料是否够（A 级 ≥1）
2. 材料够但组织不起来？            → 回阶段 4 补"对接写法"
3. 写法写了但没话说？              → 检查是否缺少"对比项"（同一现象在另一时段的形态）
4. 反复绕圈？                      → 可能是论点重复（两节在证同一件事）→ 合并
```
