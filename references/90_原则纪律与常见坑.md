# 90　贯穿纪律与跨阶段常见坑（总表）

## 一、四条贯穿纪律

| # | 纪律 | 一句话 |
|---|---|---|
| 1 | **先定引用单元，再决定落盘方式** | 引用单元是设计输入，不是事后补救 |
| 2 | **事实冻结与版本管理** | 确认过的事实只写一版；结构性变更先版本化 |
| 3 | **诚实标注优先于表面完整** | 宁可标"待核"，不可写错信息 |
| 4 | **一切引用可核验** | 编号能一键跳原件；层级不得越级 |

## 二、跨阶段常见坑总表

### A. 选题与结构

| 坑 | 症状 | 防法 |
|---|---|---|
| 命题不可证伪 | "某地某文化研究"——写到最后没有结论 | 自问"若它是错的会怎样" |
| 大纲有"多余节" | 某节写不出论点 | 每节必须答"要证明什么" |
| 结论引入新材料 | 结论章出现前文没论证的证据 | 结论只用前文叶子 |
| 时段划分顺手均匀 | 划分与实际统治结构变化无关 | 每一刀都要对应条件变化 |
| 体例"到时再看" | 写完才发现引注制式全错 | 阶段 0 就提取执行版 |

### B. 收集与获取

| 坑 | 症状 | 防法 |
|---|---|---|
| 无针对性 | 收了一堆用不上的 | 每条必须指到小节 |
| 时段不符 | 抓了背景时段的大批材料 | 时段铁律：先判时段再决定收不收 |
| 未记授权 | 写作时不敢用或重复求证 | 采集时记"可引用性" |
| 未记引用层级 | 到了写作才发现只能引到题名 | 采集时标层级 |
| 站点会话语义不清 | 只 GET 不 POST，结果为空 | 带隐藏字段与会话重放 |
| 编码误判 | 旧编码 CSV 按 utf-8 解成乱码 | 按 `cp932` / `GB18030` / `EUC-KR` 依次回退解码 |

### C. 语料库工程（**本项目事故集中区**）

| 坑 | 症状 | 防法 |
|---|---|---|
| **按"爬取动作"落盘** | 一条材料有多个"家"，引用无法核验 | **按"引用单元"落盘**；多轮检索结果**先去重建全集** |
| **B 方案的聚合文件不是全集** | 同一条目有多个归属 | 去重后建全集（可再分卷） |
| **静默丢弃** | 取不到编号的条目被 `if id:` 跳过 → 上报"全部未定位" | **命中但取不到编号也要如实报** |
| **未做归一化** | 全角/半角数字差异导致漏配 | 比对前 `NFKC` 归一（两侧都做） |
| **文件名/stem 混用** | 拿 `p.stem` 套带扩展名的正则 → 恒不匹配 | 明确用 `p.name` 还是 `p.stem` |
| **启发式猜编号** | 把无关年份也链进去 | **定不了就不写编号**，绝不猜 |
| 编号重排 | 插入新文件导致已有编号顺移 | 冻结机制；跑两次变动＝0 |
| 台账占位文字 | 引用格式列写"按格式从原文补全" | 自动生成的字段**不得留占位符** |
| 计数口径错 | 把格式化索引文本当史料量（虚高十余倍） | 统计只算**史料内容部分** |

### D. 分析

| 坑 | 症状 | 防法 |
|---|---|---|
| 综述代替卡片 | 只写概览，无法逐条引用 | **逐条卡片**，每条独立 |
| 三问缺失 | 直接谈内容，不问来源与动机 | 三问先答 |
| 无"不得用它证明什么" | 材料被过度使用 | 每条写界限 |
| 一手二手混列 | 研究判断被当一手材料 | 显式分列 |
| 只抽前几页判断 | 漏判大部头扫描卷 | 全页级审计，别只看开头 |

### E. 写作

| 坑 | 症状 | 防法 |
|---|---|---|
| 资料堆积 | 一段只摆材料不分析 | 段落骨架五步 |
| 空议论 | 只分析不落材料 | 同上 |
| 孤证 | 一条材料下结论 | ≥2 组独立来源 |
| 越级引用 | 据题名陈述内容 | 只引到題名·日期 |
| 编号不连续 | 增删段落导致跳号 | 最后统一按出现顺序重编 |
| 术语不一致 | 同一概念多种译法 | 建立专名表 |

### F. 交付与归档

| 坑 | 症状 | 防法 |
|---|---|---|
| 链接模式选错 | 用绝对路径，换机全废 | 交付用**包内相对路径** |
| 排除规则失效 | "轻量版"压出几 GB | 用**显式文件清单**而非 `-xr!` 模式 |
| 超链接正则漏位数 | 序号 ≥1000 的条目不成链接 | 正则容许 3–4 位序号 |
| 删除不释放空间（受管控环境） | 删完磁盘没变 | 先 `truncate(0)` 再删 |
| 批量删除被拦截 | 一轮删过多，进程被杀 | 分小批；优先"重写而非删除" |
| 中间产物入库 | 包内出现 .tmp、嵌套 Word 目录 | 交付前扫一遍目录树 |

## 三、六个"一句话自检"（随时可用）

```
① 这条材料将来在注释里怎么出现？
② 它对应磁盘上的什么？能否一键跳过去？
③ 这个论断的第二组独立来源在哪？
④ 这条材料不证明什么？（写下来）
⑤ 我引的是"题名"还是"内容"？层级对不对？
⑥ 换一台机器、换一个人，能不能自己核验我说的每一条？
```

**最后一问通不过，整条链就要回炉。**
