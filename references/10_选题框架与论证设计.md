# 10　选题框架与开题

## 1. 核心命题：必须"可论证"，而不是"可描述"

**区分**：
```
✗ 描述型：「某地区某文化研究」           → 没有论点，写成一本书也没有结论
✗ 常识型：「外部支配对当地文化有影响」   → 无需论证
✓ 可论证型：「某文化自主性从『被征用的工具』转变为『自我定义的目的』」
                                        → 有转变、有机制、有可证伪的落点
```
**自检**：把命题写成一句话，问自己——**"如果这个命题是错的，会是什么样子？"**
答不出来，说明它不可证伪，不是学术命题而是立场表态。

### 常见可用的命题形态
| 形态 | 句式 | 适用 |
|---|---|---|
| **转变型** | 从 A 转变为 B | 长时段、有阶段可分 |
| **机制型** | X 通过 Y 机制导致 Z | 有中介变量 |
| **比较型** | 同一对象在两个条件下呈现不同形态 | 有两个可比时段/地区 |
| **辩证型** | 同一事物同时具备相反属性（如"既是工具，也是目的"） | 材料本身有张力 |

## 2. 时段划分：服务于命题，不是讨好材料

**原则**：时段划分的每一刀，都要**对应统治主体/外部条件的实质变化**，而不是为了均匀。

- 例：`分期一（条件甲：如政体性质变化）` / `分期二（条件乙：如制度变化）` / `分期三（条件丙：如语体变化）`
  —— **每一刀都要能说出「变了什么」**，说不出就别切；
- **背景时段**（最早的时段）篇幅**最小**，只交代"起源形态"；**核心时段**才是论证重心。

⚠️ **时段铁律的连带效应**：一旦确定了"背景时段不铺开"，那么**该时段的材料在收集阶段就要限量**——
否则会出现"收了一堆用不上的料"（**实测踩过**：把前朝的传统工艺资料抓了 700 条，全用不上）。

---

## 3. 论点树：大纲 = 一棵可检验的树

```
核心命题（根）
├── 第一章 背景/起源（干）
│   ├── 1.1 分论点（枝）→ 1.1.1 论据位（叶）
│   └── 1.2 分论点
├── 第二章 第一时段（干）
│   └── …
└── 第三章 第二时段（干）
    └── 3.3 四维度（文学/记忆/运动/身份）← 并列枝
结论（果：三到四条，每条回指前文证据）
```

**三条检验**：
1. **每片叶子都要能回答"要证明什么"**——答不出的叶子，就是多余的节；
2. **同级叶子应当互斥且穷尽**（如"四维度"之间不重叠、合起来覆盖）；
3. **结论只能由前文的叶子支撑**，不得在结论里引入新论据。

---

## 4. 时间线：倒排，且留缓冲

```
提交 ── 预答辩 ── 修改 ── 初稿 ── 资料收集 ── 开题
   ↑        ↑        ↑       ↑         ↑
 每段都写清"产出物"，而不是"做什么"
```
**产出物导向**：不要写"整理资料"，要写"资料台账＋交付包 v1"。
**留缓冲**：每段预留 20–30% 时间给"没想到的问题"（例如某库需要缩微胶卷、某文件需馆际互借）。

---

## 5. 体例规范：必须提取成"执行版"

培养单位的撰写规范（几十页 PDF）**不能直接拿去写**，要提取成一张**可执行表**：

```
字数：正文 ___ 字（区间 ___–___）；摘要 ___ 字（中英各一）；关键词 ___ 个
引注：□顺序编码制（正文 [n]）  □作者—年份制
参考文献类别：___（如：图书/期刊/会议论文集/专利/学位论文）
著录细节：分隔符 ___；页码连接符 ___；是否写 [M]/[J] 类型标识 ___
量：≥ ___ 篇，其中外文 ≥ ___
版式：一级标题___ 二级___ 三级___ 正文___（字号/字体/行距/每行字数）
页边距：上/左 ≥ ___mm；下/右 ≥ ___mm
提交物：封面/摘要/目录/正文/参考文献/致谢/附录 ___（顺序）
```
**关键动作**：拿到规范后**当天就提取**，并在下一次与导师沟通时确认两处易错点：
**（a）一手史料（档案）在参考文献表里是否单列**；**（b）网页材料是否入表**。
（很多规范**根本没列档案与网页类型**——这时必须问，不能自己发明。）

## 6. 开题报告的要件（通用骨架）

```
1 选题的目的及意义      —— 命题 + 为什么值得做（理论 + 现实）
2 选题的内容概述        —— 论点树逐节展开 + 提纲（**提纲与正文目录必须一致**）
3 国内外研究现状        —— 按类别梳理 + **每类末尾一句"但……"**（立论缝隙）
4 研究方法与创新点      —— 方法与材料**一一对应**（避免"方法悬空"）
5 进度安排              —— 倒排时间线
6 参考文献              —— 按体例著录
```
**最容易出问题的两处**：
- **"内容概述"与"提纲"不一致**（前者说四章，后者写五节）；
- **研究方法只列名词**（"文献分析法、历史分析法"），不说明**用哪些材料、怎么用**。
