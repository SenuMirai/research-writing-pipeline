# 07　工具脚本说明

四个脚本，**纯 Python 标准库**（3.8+），路径全部来自 `config.json`，**无硬编码**。

---

## 0. 通用约定

```bash
python scripts/<脚本>.py --config config.json [...]
```
- **退出码 0 = 通过**，非 0 = 不通过（便于接进 CI 或批处理）。
- 所有输出文件**一律 UTF-8-BOM**（Excel 直接打开不乱码）。
- 读取时按配置的 `encoding`，并**自动回退** `utf-8-sig → utf-8 → 旧编码 → shift_jis`。

---

## 1. `registry.py` —— 编号注册表（含冻结）

```bash
python scripts/registry.py --config config.json          # 生成/更新注册表
python scripts/registry.py --config config.json --check   # 只校验，不写盘
```

**做什么**
- 按 `config.libraries[].glob` 扫描文件，**排序固定**（按相对路径）；
- **已有编号沿用不移位**；新文件领"该前缀下一个未用号"；
- 输出 `{相对路径: {编号, 名称, 库, 引用单元, 策略, 层级}}`。

**输出示例**
```
注册表：5487 个文件｜唯一编号 5487｜重复 0
   A:   3234  ✅ 与预期一致   示例库A：档案全文
   B:    198  ✅ 与预期一致   示例库B：报纸见出（全集按年分卷）
新旧编号变动 0（必须为 0）｜本次新发号 132
```
**关键指标**：`新旧编号变动` **必须为 0**。若非 0，脚本会逐个打印变动项并以退出码 1 失败。

## 2. `dedupe_corpus.py` —— 去重建"全集"

```bash
python scripts/dedupe_corpus.py --config config.json --library B
python scripts/dedupe_corpus.py --config config.json --library B --verify   # 只报告
```

**做什么**
- 读 `config.libraries[B].glob` 命中的**全部产物**（多轮检索结果）；
- 按 `dedupe_key` 指定列**去重**（键名对不上表头时退化为按列序）；
- 按 `partition_by`（如 `日付[:4]`）**分卷**；
- 输出 `全集_<卷>.csv`（**额外附"命中来源数／命中来源文件"列**，保证溯源可查）
  ＋ `_去重报告.json`（含**抽样 20 条**供人工核对）。

**输出示例**
```
输入行 28 万余｜去重后 17 万余｜重复率 38.7%
分卷：{"1946": 73, "1947": 210, ..., "2011": 3676}
```

**为什么要留"命中来源"列**：去重后仍要知道"这条来自哪几份原始产物"，
否则**无法回答"我是不是漏了哪个来源"**。

## 3. `check_contract.py` —— 契约自检

```bash
python scripts/check_contract.py --config config.json \
    --ledger ledger/总台账.xlsx --md-dir ./07_按大纲分析
```

**检查三项**
| # | 检查 | 判据 |
|---|---|---|
| ① | 编号冻结 | `registry.py --check` 连跑两次，**退出码均为 0** |
| ② | 台账完整 | **提要为空 = 0**；**粒度列全部落在四级之内** |
| ③ | 编号完整性 | 扫描 `--md-dir` 下所有 md，**裸编号 = 0** |

（②需 `openpyxl`；未装则跳过并提示。）

## 4. `check_links.py` —— 链接自检

```bash
python scripts/check_links.py --docx-dir ./Word版
python scripts/check_links.py --docx a.docx b.docx
```

**做什么**
- 用 `zipfile` 读 `word/_rels/document.xml.rels`，取所有 `TargetMode="External"` 的目标；
- **URL 解码**（`%20` 等）后判定**目标文件是否存在**（相对文档目录解析）；
- 打印**断链清单**（截尾显示）。

**判读要点**
- **断链必须为 0**；
- 若断链**集中出现**，说明**包被移动过或文件被改名** →
  **应重跑生成器（改回包内相对路径），而不是逐个手改链接**。

## 5. 建议的自检流水线

```bash
#!/usr/bin/env bash
set -e
python scripts/outline_tree.py    --outline 大纲.md --out outline.json      # 阶段0 结构自检
python scripts/registry.py        --config config.json                      # 阶段3 编编号
python scripts/dedupe_corpus.py   --config config.json --library B          # 阶段3 去重全集
python scripts/registry.py        --config config.json                      # 再跑一次 → 变动必须 0
python scripts/check_contract.py  --config config.json --ledger ledger/总台账.xlsx --md-dir ./分析
python scripts/check_links.py     --docx-dir ./分析/Word版
python scripts/check_writing_conventions.py --config config.json --md-dir ./正文   # 阶段6 体例
echo "✅ 全部自检通过，可交付"
```

**任一环节失败即中断**（`set -e`）——**不允许"带着已知问题"进入下一阶段**。

---

## 6. `outline_tree.py` —— 大纲 → 结构化配置＋结构自检（阶段 0）

```bash
python scripts/outline_tree.py --outline 大纲.md --out outline.json
```
**做什么**
- 解析 markdown 大纲（支持 `# 第一章 …`、`## 1.1 …`、`### 1.1.1 …`、`## 一、…`、`# 结论`）；
- 输出结构化 JSON：`{code, chap, title, level, point, kw}`，**即阶段 4「按大纲匹配」的输入**；
- **结构自检**：① 同层级编号是否连续 ② 层级是否畸形（仅在存在数字章号时校验父节点）③ 节点是否有标题；
- 列出**叶子节点**，提示人工补齐 `point`（这节要证明什么）与 `kw`（检索词）。

**判读要点**：**答不出 `point` 的节，就是多余的节**——这是删节或改大纲的信号。

## 7. `check_writing_conventions.py` —— 体例与引注的机械自检（阶段 5–6）

```bash
python scripts/check_writing_conventions.py --config config.json --md-dir ./正文
python scripts/check_writing_conventions.py --md-dir ./正文 --body-only 第一章 第二章
```
**检查七项**
| # | 项 | 判据 |
|---|---|---|
| ① | 正文字数 | 与配置的区间比对 |
| ② | 摘要字数 | 自动定位「摘要/Abstract」块 |
| ③ | 关键词个数 | 兼容 `关键词：a；b` 与 `# 关键词` 换行两种写法 |
| ④ | **引注编号连续性** | **跳号必须为 0**；起点必须为 1 |
| ⑤ | 参考文献 | 条目数达标；**外文占比**达标 |
| ⑥ | **标题层级** | **跳级数为 0**（如 `#` 直接到 `###`） |
| ⑦ | 残留占位符 | 统计"待核/待补/TODO/XXX"（供人工确认） |

**判读要点**：**只做机械判定**——"字数/连续性/跳级"它能管；
**"这条材料用对没有、性质分得清不清"它管不了**，那是史料批判三问的工作。
