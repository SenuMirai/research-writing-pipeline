# 05　按大纲生成「文献史料分析」

目标：产出一套 Word，**目录结构与论文大纲逐字一致**，每条材料都带
**编号（可点击）·原文·译文·所体现的内容·对接论文的写作方法·引用注释格式**。

---

## 1. 先把大纲变成"可计算的结构"

```python
OUTLINE = [
    dict(code="2.2.1", chap="第二章", title="教育与宣传体系：服务于冷战框架",
         point="教育制度、教科书、文化会馆、广报共同构造冷战叙事",   # ← 本节要论证什么
         kw=["教育","学校","教科书","広報","宣伝","文化会館","文部","教員","米国民政府"]),
    ...
]
```
- `code` 用**论文的小节号**（`1.1.1`、`2.2.1`、`3.3.4`；绪论用 `序.1`），**与大纲一一对应**；
- `point` 写"**本节要证明什么**"——写作时的准绳，也方便导师审阅；
- `kw` 是**检索词库**（中日英混写，专名优先）。

## 2. 匹配打分（把上千条材料分派到各小节）

```python
def score(rec, node):
    hay = rec["标题"] + rec["摘要"] + rec["原文"][:600]
    n   = sum(1 for k in node["kw"] if k in hay)
    base = (6.0 if rec.get("已标定小节") == node["code"] else 0) + min(n, 6) * 1.0
    if base == 0: return 0
    return base * (0.6 + 0.4 * period_fit(node["code"], rec["年份"]))   # 时段加权
```
**分档**：
| 档 | 判据 | 用法 |
|---|---|---|
| **A** | 已标定本节点位，或命中 ≥3 个关键词且时段吻合 | **主证据**，直接入注 |
| **B** | 命中 1–2 个，或需转译 | **旁证**／背景 |
| **C** | 仅间接相关 | 备查，一般不入注 |

**时段硬规则**（以"三时段比较研究"为例）：背景章（第一分期）材料**一律不铺开**；
核心分期优先；背景分期只保留必要前提。

## 3. 生成"写作材料包"再动笔

不要对着上万条材料直接写。先按章导出**精简材料包**：

```
每节给：
  论证要点
  候选统计（A/B/C 各多少）
  按库配额抽样的 10–20 条：编号｜库｜日期｜粒度｜题名｜原文片段｜摘要｜引用格式
```
**抽样要跨库**（否则会被某一库淹没——**实测踩过**：某节 45 条候选里 40 条都来自同一库）。

## 4. 每条材料必须给齐六项

```
### [编号]｜等级｜<题名>
- **建议用于**：<正文哪一处>——<起什么作用>
- **① 谁写的**：<作者/摄制者身份、职务、立场>
- **② 为何写、写给谁**：<动机与预设读者>
- **③ 如何流传至今**：<从产生到今天的路径：底片/缩微/转写/OCR；有无删改>
- **原文**：> <原语言，逐字>
- **译文**：> <中文>
- **所体现的内容**：<分析>  ⚠️ **不得用它证明什么**：<界限>
- **对接论文的写作方法**：<放到该节哪个位置、怎么写、结论句是什么>
- **引用注释格式**：<可直接复制；分"随文注体"与"参考文献体">
```

### 三条强制纪律
1. **史料批判三问答不出，先别分析内容**（见第 5 节）；
2. **每条必须写"不得用它证明什么"**——这是防"孤证立论／性质不分"最有效的一句；
3. **编号必须是超链接**，且**裸编号 = 0**。

## 5. 史料批判三问（每条先答，再谈内容）

| 问 | 要回答 | 答不出的后果 |
|---|---|---|
| **① 谁写的？** | 作者／拍摄者／发布机构的具体身份、职务、立场 | 无法判断他"能看见什么、看不见什么" |
| **② 为何写、写给谁？** | 写作/拍摄动机与预设读者：内部报告、对外宣传，还是个人记述 | 无法判断他"故意不说什么" |
| **③ 如何流传至今？** | 从产生到进入今天这个数据库，经过谁的手、有无删改、现存哪一版 | 无法判断"我们今天看到的到底是哪一版" |

**按材料类型的常见答案**（示例，实际须逐条核实）：
- **官方宣传照片**：拍摄方＝统治机构；目的＝对外宣传治理成效；流传＝机构底片后代数字化 → **画面是选择的结果，不等于社会全貌**；
- **当事人证言**：讲述者＝当事人；对象＝后世调查者；流传＝录音转写（**注意"方言未能转写"处**）→ **记忆会随场合重组**；
- **报纸见出**：作者＝报社记者；对象＝当地读者；流传＝第三方转写 → **只到题名层级**；
- **研究论文**：作者＝研究者；对象＝同行 → **是判断，不是材料**，不得与一手史料混列。

## 6. 机械化阅读四症状（自查表）

| 症状 | 表现 | 本流程的防线 |
|---|---|---|
| **孤证立论** | 一条材料直接得出结论 | 每个判断**≥2 组独立来源**（跨库、跨性质） |
| **性质不分** | 把公报题名当新闻读、把回忆录当庭审记录读 | 每条**显式标注资料性质**＋"不得用它证明什么" |
| **文本透明化** | 默认文字＝事实，看不见套话与修辞 | 三问第②问＋**对关键词逐词解**（如"解放""亲善""名目""異化"） |
| **不问来源出处** | 不问经过谁的手、有没有被删改 | 每条必附**完整出处＋在线来源＋版本说明** |
