# 05　体裁适配：学位论文／期刊论文／专著／研究报告

> **同一套流程，不同体裁下要改的是"结构与交付要求"，不是方法本身。**
> 先定体裁，再据此决定：框架形态、篇幅、引注位置、审校重点。

---

## 一、四种体裁对照表

| 维度 | **学位论文** | **期刊论文** | **专著** | **研究报告／结题报告** |
|---|---|---|---|---|
| **核心目的** | 证明**研究能力**（方法规范、文献充分、工作量可查） | 提供**新知识与新论点**（贡献优先） | 建立**系统论述** | 回答**委托方的问题** |
| **总篇幅** | 硕 3–5 万字／博 8–15 万字（按院系规范） | 中文 0.8–2 万字／英文 6,000–12,000 词 | 20 万字以上 | 1–10 万字 |
| **结构** | 绪论—（文献综述）—各章—结论—参考文献—附录 | 引言—文献与问题—材料与方法—分析—结论—参考文献 | 章—节—结论 | 执行摘要—背景—方法—发现—建议—附录 |
| **文献综述** | **独立成节／章**（显式、充分） | 压缩进引言或独立一节（精炼） | 融入各章 | 简要（背景性） |
| **方法交代** | 详细（可复现） | 简练但足够 | 分散于各章 | 详细（委托方要评估可信度） |
| **结论的写法** | 总结 + 局限 + 展望 | 结论 + 意义（不宜过长） | 综合收束 | **建议要可执行** |
| **引注位置** | 常为**章末或文末**，正文序号制 | 常为**文末**（顺序编码或作者—年份） | 常为**页下注** | 常用注 + 附录数据 |
| **附录** | 允许且常需要（大表、材料清单、转录） | 一般不放（或极简） | 可以有 | 常需要（问卷、数据表、访谈提纲） |
| **匿名评审** | 盲审时需去作者信息 | **必需**（正文+文件属性） | 少见 | 一般不 |
| **交付形态** | 按院系：Word/PDF（含封面、目录、页码） | 按刊物：投稿系统/模板（Word/LaTeX） | 按出版社：含图版与版权页 | Word 或 PPT 汇报版 |

## 二、各体裁的**额外**出口自检

### 学位论文
```
[ ] 结构要件齐全且顺序正确（封面/摘要中英/目录/正文/参考文献/致谢/附录）
[ ] 摘要字数、关键词数、正文字数达标（按院系规范）
[ ] 文献量达标、外文占比达标
[ ] 版式（字号/行距/页边距/页眉页脚）逐项对照
[ ] 盲审要求：正文与文档属性中无姓名、学号、致谢等可识别信息
[ ] 图表编号连续、图注完整、图版标注出处
```

### 期刊论文
```
[ ] 目标刊物的《投稿须知》逐项对照（篇幅/摘要形式/关键词/引注体系/图表数量）
[ ] 与刊物定位相符（栏目、学科、方法取向）——**先看近三年同题文章**
[ ] 贡献明确（作者在引言里说清"本文新在哪里"）
[ ] 匿名：正文中无自引暴露（如"笔者前文"改写为第三人称引用）
[ ] 图表随文位置、分辨率、色彩模式符合要求
[ ] 参考文献遵循该刊体系（顺序编码 vs 作者—年份；是否写类型标识）
[ ] 投稿信（cover letter）与推荐审稿人（如要求）
```

### 专著
```
[ ] 章节之间的逻辑与交叉引用一致（不重复、不断裂）
[ ] 索引（人名/术语/地名）与专名表一致
[ ] 图表清单与权属说明（图片授权）
[ ] 稿约中的注释体系（页下注/尾注）与层级
```

### 研究报告
```
[ ] 执行摘要能独立读懂（委托方常只看它）
[ ] 建议部分：可执行、有主体、有时间范围（"谁在何时做什么"）
[ ] 数据来源与局限交代清楚（避免过度推论）
[ ] 交付含汇报版（PPT）与全文版两个形态
```

## 三、体裁对**前期流程**的影响

| 阶段 | 学位论文 | 期刊论文 | 专著 | 研究报告 |
|---|---|---|---|---|
| **0 框架** | 论点树完整，工作量可查 | **单一核心论点**＋充分论证 | 多维但要有主线 | 问题导向（从委托方问题反推） |
| **1 收什么** | 求"充分"（评审看文献量） | 求"精准"（只收直接相关的） | 求"系统" | 求"针对"（回答委托问题） |
| **2 检索** | 广撒网＋核心精读 | **快而准**，先看同题近作 | 长期积累 | 掌握委托方内部资料 |
| **3 语料库** | 需要完整台账（应对查证与答辩） | 精而少，台账可轻 | 长期可用 | 数据留档（可被复核） |
| **4 分析** | 逐条卡片，体量可大 | 只做与核心论点直接相关的条目 | 按章组织 | 按"问题—发现"组织 |
| **5 写作** | 可铺陈 | **惜字如金**，每段都要推进论点 | 可展开 | 结论先行 |
| **6 审校** | 13 类全查 | **格式合规优先**（不合规直接退稿）＋贡献清晰 | 交叉引用与索引 | 建议可行性 |

## 四、一条实用建议：**先写"最难的体裁"再降级**

如果同一研究既要写学位论文、又要投期刊：
1. **先按学位论文写全**（材料、分析、论证完整）；
2. 再**抽出单篇期刊论文**：只取一个核心论点，把其余材料转为背景或另投；
3. 切分时注意**自我重复与一稿多投**的边界（同一数据的不同论点、不同分析角度可以分别是不同文章，但必须明示关系）。

> **反向操作（先写论文再补成学位论文）通常更费力**——因为学位论文要求的方法交代与文献充分度都要重新补。
